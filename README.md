About the Movie

Real Steel is a sci-fi sports drama released in 2011, directed by Shawn Levy.
It stars Hugh Jackman as a former boxer who trains a robot to fight in a high-tech boxing league.

Main Characters

Charlie Kenton – Former boxer and robot trainer

Max Kenton – Charlie’s son who discovers Atom

Atom – The underdog robot fighter

Robot List

Atom – The hero robot 

Zeus – The world champion

Noisy Boy – The flashy fighter

Fun Fact

The robot boxing scenes were created using a mix of motion capture and animatronics.
